# 勉強時間記録アプリ 要件定義書

**バージョン**: 1.0  
**作成日**: 2026-03-17  
**ステータス**: Draft

---

## 1. プロジェクト概要

### 1.1 目的

大ジャンル・小ジャンルを指定してタイマーを操作し、勉強時間を記録・可視化するWebアプリケーション。シンプルな記録機能に集中し、余計な機能を持たないことを設計原則とする。

### 1.2 ターゲットユーザー

- フェーズ1: 開発者自身（1名）
- フェーズ2: Webブラウザにアクセスできる一般ユーザー

### 1.3 設計原則

- **ミニマム**: 勉強時間の記録と可視化のみに集中する
- **低コスト**: ランニングコストを最小限に抑える
- **スケーラブル**: 将来的な多ユーザー対応を前提とした設計
- **CI/CD優先**: デプロイ・運用が自動化しやすい構成

## 2. 機能要件

### 2.1 認証・ユーザー管理

| 機能                  | 詳細                                |
| --------------------- | ----------------------------------- |
| ユーザー登録          | メールアドレス＋パスワードで登録    |
| ログイン / ログアウト | セッション管理はSupabase Authに委譲 |
| プロフィール編集      | 表示名の変更                        |
| アカウント削除        | 自身のデータをすべて削除して退会    |

### 2.2 ジャンル管理

大ジャンル・小ジャンルはユーザーごとに独立して管理する。

| 機能            | 詳細                                                                                               |
| --------------- | -------------------------------------------------------------------------------------------------- |
| 大ジャンル CRUD | 作成・一覧表示・名称編集・削除                                                                     |
| 小ジャンル CRUD | 大ジャンルに紐づけて作成・編集・削除                                                               |
| 削除時の挙動    | ジャンルを削除しても過去のセッション記録は保持する（ジャンル名はスナップショットとして記録に残す） |

**例**

```
大ジャンル: 英語
  └ 小ジャンル: TOEIC単語帳
  └ 小ジャンル: シャドーイング

大ジャンル: プログラミング
  └ 小ジャンル: Rustの本
  └ 小ジャンル: LeetCode
```

### 2.3 タイマー・記録機能

タイマーの状態はサーバーに開始時刻を保存することで、ブラウザを閉じても記録を失わない設計にする。

| 機能                 | 詳細                                                                         |
| -------------------- | ---------------------------------------------------------------------------- |
| 記録開始             | 大ジャンル・小ジャンルを選択してタイマー開始。開始時刻をDBに保存             |
| 一時停止 / 再開      | 一時停止中の時間は計測から除外する。区間（interval）単位でDBに保存           |
| 記録停止             | タイマーを停止して正味の勉強時間を確定・保存                                 |
| ブラウザ再起動の復元 | ログイン後にアクティブセッションが存在する場合、タイマーを復元して継続できる |
| 同時タイマー         | 1ユーザー・同時に1セッションのみ（複数同時起動は不可）                       |

**セッションのライフサイクル**

```
[開始] → running
  → [一時停止] → paused
    → [再開] → running
  → [停止] → completed
```

### 2.4 記録の閲覧・編集

| 機能           | 詳細                                                                   |
| -------------- | ---------------------------------------------------------------------- |
| 記録一覧       | 日付・大ジャンル・小ジャンル・勉強時間を一覧表示。ページネーションあり |
| 記録の手動編集 | 勉強時間（分）を直接修正できる                                         |
| 記録の削除     | 1件単位で削除                                                          |
| フィルタ       | 大ジャンル・期間でフィルタリング                                       |

### 2.5 可視化・ダッシュボード

グラフはすべて**積み上げ棒グラフ**を基本とし、大ジャンルを軸に小ジャンルの内訳を色分けで表示する。

| 機能               | 軸                             | 積み上げ単位           | 詳細                                       |
| ------------------ | ------------------------------ | ---------------------- | ------------------------------------------ |
| 日別グラフ         | X軸: 日付、Y軸: 勉強時間       | 小ジャンルごとに色分け | 直近N日間（7日・30日を切替可能）           |
| 大ジャンル別グラフ | X軸: 大ジャンル、Y軸: 合計時間 | 小ジャンルごとに色分け | 指定期間内の合計を大ジャンル単位で比較     |
| 累計サマリー       | -                              | -                      | 今日・今週・今月の合計勉強時間をカード表示 |

**表示仕様の補足**

- 各棒をホバー（またはタップ）すると、小ジャンルごとの時間と割合をツールチップで表示
- 期間フィルタ（今週 / 今月 / 過去30日 / カスタム）を共通で提供
- 小ジャンルの色はジャンル設定時に自動でアサインし、凡例をグラフ下部に表示

## 3. 非機能要件

| 項目             | 要件                                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| 可用性           | Cloudflare Workers / Supabaseの無料枠SLAに準拠                                                   |
| レスポンス       | タイマー操作のAPIは500ms以内に応答                                                               |
| セキュリティ     | 全APIエンドポイントで認証トークン（JWT）の検証を必須とする。他ユーザーのデータへのアクセスを禁止 |
| スケーラビリティ | Cloudflare Workersのエッジ実行により、ユーザー数増加に対してスケールアウト可能な構成             |
| ランニングコスト | 小規模運用時は無料枠内に収める                                                                   |

## 4. 技術スタック

### 4.1 構成図

```
[ブラウザ]
    │
    │ HTTPS
    ▼
[Cloudflare Pages]         ← React (Vite) / フロントエンド
    │
    │ REST API / HTTPS
    ▼
[Cloudflare Workers]       ← Hono / バックエンド
    │
    │ SQL over HTTPS
    ▼
[Supabase]                 ← PostgreSQL / 認証 (Supabase Auth)
```

### 4.2 技術選定

| レイヤー          | 技術                      | 選定理由                       |
| ----------------- | ------------------------- | ------------------------------ |
| フロントエンド    | React (Vite) + TypeScript | 軽量・高速ビルド               |
| バックエンド      | Hono (TypeScript)         | Cloudflare Workers対応・軽量   |
| データベース      | Supabase (PostgreSQL)     | 無料枠・マネージド・スケール可 |
| 認証              | Supabase Auth             | DBと同一サービスで管理が容易   |
| ホスティング (FE) | Cloudflare Pages          | 無料・CDN・GitHubと連携        |
| ホスティング (BE) | Cloudflare Workers        | 無料枠大・エッジ実行           |
| CI/CD             | GitHub Actions            | Pagesへの自動デプロイ          |

## 5. データモデル

### 5.1 テーブル定義

#### `users`（Supabase Authが管理）

| カラム       | 型          | 説明           |
| ------------ | ----------- | -------------- |
| id           | uuid (PK)   | ユーザーID     |
| email        | text        | メールアドレス |
| display_name | text        | 表示名         |
| created_at   | timestamptz | 登録日時       |

#### `categories`（大ジャンル）

| カラム     | 型                | 説明         |
| ---------- | ----------------- | ------------ |
| id         | uuid (PK)         | -            |
| user_id    | uuid (FK → users) | 所有ユーザー |
| name       | text              | 大ジャンル名 |
| created_at | timestamptz       | -            |

#### `subcategories`（小ジャンル）

| カラム      | 型                     | 説明         |
| ----------- | ---------------------- | ------------ |
| id          | uuid (PK)              | -            |
| user_id     | uuid (FK → users)      | 所有ユーザー |
| category_id | uuid (FK → categories) | 大ジャンル   |
| name        | text                   | 小ジャンル名 |
| created_at  | timestamptz            | -            |

#### `study_sessions`（勉強セッション）

| カラム           | 型                     | 説明                                       |
| ---------------- | ---------------------- | ------------------------------------------ |
| id               | uuid (PK)              | -                                          |
| user_id          | uuid (FK → users)      | -                                          |
| category_id      | uuid (FK, nullable)    | 大ジャンルID（削除されてもNULL化して保持） |
| subcategory_id   | uuid (FK, nullable)    | 小ジャンルID（同上）                       |
| category_name    | text                   | 大ジャンル名スナップショット               |
| subcategory_name | text                   | 小ジャンル名スナップショット               |
| status           | text                   | `running` / `paused` / `completed`         |
| started_at       | timestamptz            | 開始時刻                                   |
| ended_at         | timestamptz (nullable) | 終了時刻                                   |
| duration_seconds | integer (nullable)     | 正味の勉強時間（秒）。完了時に確定         |
| created_at       | timestamptz            | -                                          |

#### `session_intervals`（一時停止区間）

| カラム     | 型                         | 説明                                       |
| ---------- | -------------------------- | ------------------------------------------ |
| id         | uuid (PK)                  | -                                          |
| session_id | uuid (FK → study_sessions) | -                                          |
| started_at | timestamptz                | 区間開始（タイマー再開時刻）               |
| ended_at   | timestamptz (nullable)     | 区間終了（一時停止時刻）。NULLは現在計測中 |

## 6. API設計（概要）

### 認証

```
POST   /auth/signup       ユーザー登録
POST   /auth/login        ログイン
POST   /auth/logout       ログアウト
```

### ジャンル管理

```
GET    /categories                      大ジャンル一覧
POST   /categories                      大ジャンル作成
PATCH  /categories/:id                  大ジャンル編集
DELETE /categories/:id                  大ジャンル削除

GET    /categories/:id/subcategories    小ジャンル一覧
POST   /categories/:id/subcategories    小ジャンル作成
PATCH  /subcategories/:id              小ジャンル編集
DELETE /subcategories/:id              小ジャンル削除
```

### セッション（タイマー）

```
POST   /sessions               記録開始
POST   /sessions/:id/pause     一時停止
POST   /sessions/:id/resume    再開
POST   /sessions/:id/stop      停止・完了
GET    /sessions/active        アクティブセッション取得（復元用）
```

### 記録

```
GET    /sessions               記録一覧（フィルタ・ページネーション）
PATCH  /sessions/:id           記録編集（duration_seconds の手動修正）
DELETE /sessions/:id           記録削除
```

### 統計・可視化

```
GET    /stats/daily            日別・小ジャンル別の勉強時間（積み上げグラフ用）?from=&to=
GET    /stats/by-category      大ジャンル別・小ジャンル別の合計時間（積み上げグラフ用）?from=&to=
GET    /stats/summary          今日・今週・今月のサマリー
```

レスポンスは日付（または大ジャンル）ごとに `breakdown` 配列を持ち、小ジャンル単位の秒数と所属大ジャンル名を含む。フロントエンドはこれをそのまま積み上げ棒グラフのデータソースとして利用する。
